## 🎯 Project Goals

The primary goal of this website is to serve as the digital storefront for Blue Crescent. It aims to:

1.  **Introduce the Team:** Present our talented team of engineers and designers.
2.  **Showcase Our Work:** Display a portfolio of our key projects with descriptions and technologies used.
3.  **Inform Visitors:** Clearly communicate our company values, our development process, and our mission.
4.  **Generate Leads:** Provide a clear and simple way for potential clients to get in touch.

---

## ✨ Key Features

-   **Multi-Page Layout:** A clean and intuitive navigation structure with dedicated pages for Home, Portfolio, About Us, and Contact.
-   **Dynamic Portfolio:** An interactive project gallery that can be filtered by categories like Web Development, Mobile Apps, and IoT Solutions.
-   **Meet the Team Section:** A detailed "About Us" page introducing the members of the Blue Crescent team, complete with bios and social media links.
-   **Company Values & Process:** Dedicated sections explaining the core values (Innovation, Quality, Collaboration) and the 4-step development process.
-   **Interactive Contact Form:** A user-friendly contact form with fields for name, email, subject, and message for easy communication. *(Note: The current implementation simulates the submission process on the frontend.)*
-   **Responsive First:** The entire website is built with a mobile-first approach, ensuring a seamless experience on all screen sizes.

---

## 🛠️ Technology Stack

This project is built using a modern and efficient frontend technology stack.

-   **Core Framework:** [React](https://reactjs.org/) (via [Vite](https://vitejs.dev/))
-   **Routing:** [React Router DOM](https://reactrouter.com/) for seamless client-side navigation.
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/) for a utility-first, responsive design system.
-   **Icons:** [Lucide React](https://lucide.dev/) for a clean and consistent icon set.

## 🚀 Getting Started

To get a local copy up and running, please follow these simple steps.

### Prerequisites

-   Node.js (v18.x or newer)
-   npm or yarn package manager

### Installation & Launch

1.  **Clone the repository to your local machine:**
    ```bash
    git clone [https://github.com/your-username/blue-crescent-website.git](https://github.com/your-username/blue-crescent-website.git)
    cd blue-crescent-website
    ```

2.  **Install the necessary NPM packages:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```
    The application will now be available at `http://localhost:5173`.
